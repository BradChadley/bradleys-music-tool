Bradley's Music Tool
====================

A music library tool for Windows 10 and 11 (64-bit): recommendations from what you listen to, a Soulseek
search with an import that tags and files albums for you, a library browser, and a health check that
finds and repairs damaged files, bad tags and missing covers.


Starting it
-----------

1. Unpack this zip into a folder of its own, for example "Documents\Bradley's Music Tool". The app keeps
   itself up to date by replacing its own file, so it needs a folder it can write to (not "Program Files").
2. Start bradleys-music-tool.exe.
3. Windows will warn you the first time, because the app is not signed: "Windows protected your PC".
   Click "More info", then "Run anyway". Windows asks only once.
4. The app asks where your music is. Last.fm and Soulseek are optional and can be set up later in Settings.

There is no installer. To remove the app, delete its folder and the folder %LOCALAPPDATA%\music-recs
(your settings and saved lookups).


What it fetches
---------------

Only when you ask for it, from the makers' own release pages, each checked against a known checksum:

  FFmpeg          checking and converting music files           115 MB
  slskd           the Soulseek client, only if you set it up      56 MB

It looks up artist and album names at Last.fm, MusicBrainz, the Cover Art Archive, Apple's music search,
Deezer, Bandcamp and LRCLIB (lyrics). Nothing is sent to the author.


Updates
-------

Twice a day the app reads one small file from its GitHub releases. When there is a newer version it fetches
it, checks that it carries the author's signature, and puts it in the next time you restart. It never
restarts by itself. Settings, About lets you choose to be told only, or to never check.


Your files
----------

It changes files in your music folder only when you click a repair or an import. Nothing is deleted for
good: what a repair or an import replaces goes to an undo folder or the Recycle Bin, and Health's repair
history can put it back. If your library is laid out another way, choose "Look only, change nothing" at
the first start and the app will only report.

The Last.fm session and Soulseek login are kept in Windows Credential Manager, not in a file. Connect Last.fm in Settings and approve access in your browser; no API key is needed. The Soulseek
client it sets up shares none of your files and can only be reached from your own PC.

The Backup page copies and checks files in the app itself. After updating, existing backup setups need
one "Confirm folders" on the Backup page. Check the library and backup paths and drives, confirm them,
then preview the changes. A matching drive letter or disk label alone no longer identifies a backup.
Use "Set up nightly backup" to have this app handle scheduled backups. Replaced and removed copies
are kept for 30 days, and a second drive can hold another checked copy. Large removals stop for review.

Whole-backup checks report missing and unverified files separately. A check succeeds only when every
library file has a verified copy. App-data snapshots now save Cadence's library, playlists and settings,
including committed SQLite changes while Cadence is open. Previous player backups remain untouched.
If a configured or previously saved app-data folder disappears, the backup reports a failure and keeps
the previous snapshot. See README.md in the source repository for custom Cadence paths and restoration.
